# Product Overview

GL Miler is a fleet management and trip planning application built for logistics companies. The application provides:

- **Trip Management**: Create, edit, and track trips with multiple stops
- **Route Planning**: Visual route planning with HERE Maps integration
- **Fleet Tracking**: Manage trucks, drivers, and dispatchers
- **Interactive Mapping**: Real-time route visualization with polyline support
- **Data Tables**: Comprehensive data views with infinite scrolling and sorting

The application focuses on efficient trip planning with drag-and-drop stop management, real-time route calculation, and comprehensive fleet oversight capabilities.
